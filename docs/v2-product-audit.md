# v0.3.0 产品审计（Nielsen 启发式评估 + 竞品差距分析）

> 方法：[Nielsen 10 可用性启发式](https://www.nngroup.com/articles/ten-usability-heuristics/)逐条评估 + 竞品机制对照。审计对象为 v0.3.0 实机（截图 `docs/images/baseline-*.png`）。评分：✓ 良好 / △ 有缺陷 / ✗ 缺失。

## 一、启发式逐条评估

| # | 启发式 | 评分 | 发现（v0.3.0 证据） |
|---|--------|------|---------------------|
| 1 | 系统状态可见性 | △ | popup 只有当日总量，没有"现在正在记录什么"的实时反馈；badge 有预算数字但无图例说明 |
| 2 | 贴近真实世界 | ✓ | "娱乐预算""豁免"用语自然 |
| 3 | 用户控制与自由 | △ | 改判只能改"当前段"，对已入库的历史段无处理；暂停只有 30 分钟一档 |
| 4 | 一致性与标准 | △ | popup 白底 / guide 白底 / options 白底但三处风格各自为政，间距与控件样式不统一 |
| 5 | 防错 | ✗ | 规则编辑无即时校验（pattern 写错保存后静默失效）；删除规则无撤销 |
| 6 | 识别而非回忆 | ✗ | 规则语法（`re:` 前缀、通配符）全靠记忆，无内联提示；类别只有四个默认色块 |
| 7 | 灵活与效率 | ✗ | 无键盘快捷操作；改判要打开 popup 两步；无"常用动作"入口 |
| 8 | 美学与极简 | ✗ | **用户直接反馈"太丑、单调"**：纯白无层次、默认控件外观、无品牌记忆点 |
| 9 | 错误恢复 | △ | 数据清空有双重确认 ✓，但规则保存错误无提示 ✗ |
| 10 | 帮助与文档 | ✗ | 无新手引导；规则语法要翻 README |

**结论**：8 项主要缺陷中 5 项直接与"表达层"相关（8/6/10/7/4），3 项与"智能"相关（1/5/3 的根因是系统不够了解站点）。

## 二、竞品机制差距（对标 Cold Turkey / RescueTime）

| 机制 | Cold Turkey | SurfWarden v0.3.0 | 差距 → 归入迭代 |
|------|-------------|--------------------|----------------|
| 站点分组 | block lists（组内混合网站/应用、组独立日程、组级例外） | 仅类别 + 扁平规则列表，无组概念，规则无先验 | **IT2 站点情报**：内置站点目录（域名→组/标签先验）+ 规则分组 |
| 新站点的默认归属 | 手动加入组 | 无规则 → 落 neutral，用户无感知、无引导 | **IT2**：未分类站点在 popup 出现"待归类"建议卡（基于目录模糊匹配候选） |
| 组级日程 | Pro：分组定时封锁 | 无 | **IT4 专注模式**覆盖高频场景（NOW 封锁 N 分钟），全天候日程排 P3 |
| 报告 | 弱（Focus 计时） | 无报告页 | **IT3 dashboard** |
| 拦截体验 | 死板白页 + 密码锁定 | 引导页（有去学习/豁免）但视觉与信息弱 | **IT1 视觉重塑 + IT4 意图三选** |
| 正向激励 | 无 | 无（只有负向预算） | **IT3 streak + 学习时长正反馈**、**IT4 意图流** |

## 三、2.0 功能需求池（按轮归位）

- **IT1**：统一设计系统「哨站 OpsDeck」；popup 增加实时状态区（"正在记录…"+当前段）；三页面视觉统一。
- **IT2**：`siteCatalog`（内置 ~100 常用站：域名→{组, 标签, 默认类别}）；规则自动归组；popup "待归类"建议卡（一键采纳为规则）；options 规则列表显示组/标签徽章。
- **IT3**：dashboard 页（今日分段时间线、7 日柱状趋势、类别占比、24h×7d 热力图需小时级数据→先用日粒度+小时分布近似、streak、"今天 vs 7 日均值"）。
- **IT4**：专注模式（popup 一键，30/60/90 分钟，封锁全部娱乐+弹横幅倒计时）；guide 意图三选按钮组；nudge 横幅升级（显示预算读数、微型进度条）。
- **IT5**：设置强调色（青/紫/琥珀三套 OpsDeck 变体）；onboarding checklist（隐身开启/预算设置/学习目标/模板导入 四步完成度）；全站空态插画式文案；细节打磨清单逐项销号。

## 四、明确不做（2.0 边界）

- 跨设备同步 / 账号；移动端；AI 内容分类（规则+目录先验已覆盖高频场景）；全天候组日程（专注模式已覆盖高频需求，P3 再议）。
