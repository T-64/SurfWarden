# SurfWarden v3 产品方案：作息 + 德语

> 版本 v3.0，2026-10-14。取代 v2 方案（已归档到 `archive/v2/PRODUCT-v2.md`），重定位的理由见 ADR-0012。

## 0. 一句话

一个只在本机运行的浏览器扩展，管两件事：**晚上按时下线睡觉**，**把白天漫无目的刷 B 站直播、刷 X 视频的时间，换成学德语的时间**。顺带让你如实看到，电脑上的网页时间都花在了哪里。

## 1. 用户与现状

- 用户：斯图加特大学 INFOTECH 学生，2026-10 到德国。德语刚过 A1，主线是 Nicos Weg（DW），辅以 Anki 和 Language Transfer。
- 目标作息：**23:00 上床，07:30 起床**。
- 过去 10 个月的实际作息：0:30–1:00 入睡，8:00–8:30 起床，闹钟响后常赖到 9:30。目标相当于整体提前 1.5–2 小时。时差刚重置，是改作息的窗口期。
- 主要失控场景：
  1. 没有目的地打开 B 站直播或 X 视频，一看就是几十分钟。
  2. 晚上 22 点之后还在浏览器里，结果拖晚了上床。
- 精力规律：中午学德语效率最高，晚上基本学不动。**所以晚上的出口是"去睡觉"，不是"去学德语"。**

## 2. 目标与非目标

| # | 目标 | 怎么衡量 |
|---|------|----------|
| G1 | 晚上按时离开浏览器 | 报告页的"每晚最后上网时间"，每周至少 5 晚 ≤ 23:00 |
| G2 | 减少漫无目的的娱乐 | 每天娱乐总时长 ≤ 上限（默认 60 分钟）；每次进入都有明确意图和时限 |
| G3 | 德语时间增加 | 每天德语分钟数和目标对比（默认 45 分钟），按连续天数计 |
| G4 | 时间去向真实可信 | 看视频不碰鼠标也照常计时；正在进行的时长 30 秒内就会计入 |
| G5 | 全部本地 | 零网络请求、没有账号 |

**非目标：**
- 手机上的使用（插件只能看到本机浏览器，报告页会写明这一点）
- 叫你起床（插件只能看到浏览器，"首次上网时间"只作参考）
- 对抗"自己卸载或禁用插件"
- AI 分类

## 3. 概念模型

### 3.1 五个固定类别

| id | 名称 | 含义 |
|----|------|------|
| `german` | 德语 | 正向指标，有每日目标 |
| `study` | 学业 | 学校、编程、工作工具 |
| `drift` | 娱乐 | B 站、X、YouTube、直播站等，进入要过"意图闸门" |
| `private` | 私密 | 成人网站，进入要过"冷静期"（见 3.6，ADR-0015） |
| `other` | 其他 | 其余所有 http(s) 页面 |

类别是固定的，这样配置项最少。用户能调整的是"哪些网址、哪些频道属于哪一类"。

### 3.2 分类：频道比网址更具体

优先级从高到低：

1. **本段手动改判**：在 popup 里把当前这一段改成别的类别。
2. **频道规则**：B 站 UP 主（按 mid）或 YouTube 频道（按 @handle）。页面里的脚本读到频道后，在**同一个页面**上就会重新分类。
3. **网址规则**：沿用 v2 的语法（域名 / 路径 / 完整 URL / `re:` 正则），越具体的越优先。
4. 都没命中，归为 `other`。

"B 站德语课"就是这样实现的：`bilibili.com` 整站算娱乐，但标记过的德语 UP 主的视频算德语。第一次看某个 UP 主的视频时，页面上会问一次"这是德语学习吗？"，回答会被记住，之后不再问。

### 3.3 一天的三个时段

时间都可以配置：

| 时段 | 默认时间 | 娱乐页 | 其他页面 |
|------|---------|--------|---------|
| 白天 | 07:30–22:30 | 过意图闸门（见 3.4） | 放行 |
| 收尾 | 22:30–23:00 | **拦截，不能申请** | 放行，右下角显示"距上床 N 分钟" |
| 宵禁 | 23:00–07:30 | 拦截 | 只放行白名单（默认：德语、学业，以及邮箱、地图、DB 等站点），并显示"已过就寝 N 分钟"；其余页面拦截 |

**宵禁延长：** 每晚 1 次，每次 10 分钟。申请时必须写理由，理由会如实记录到报告。延长期间放行非娱乐页面；娱乐页在宵禁期永远拦截。

**逻辑日：** 一天从凌晨 05:00 开始算。所以凌晨 1 点上网，算在前一晚。

### 3.4 意图闸门（白天进入娱乐页）

1. 打开任何娱乐页（包括已经开着的标签页、站内跳转），页面先被遮住，视频暂停。
2. 遮罩上问"你想干嘛？"，可以选一个预设（放松一下 / 找东西 / 看某个具体视频），也可以自己写；然后选时长 5 / 10 / 20 分钟，不会超过今天剩余的额度。
3. **摩擦逐次递增：** 当天第 1 次要等 5 秒才能确认，之后依次是 10 / 20 / 30 / 45 / 60 秒。
4. 确认后发放一张"通行证"，按站点算（eTLD+1 的近似，比如 `bilibili.com` 同时覆盖直播）。页面右下角显示倒计时。
5. **到点后：** 遮罩"时间到"。主按钮是"去学德语"（继续上次的德语页面，或打开第一个德语入口），次按钮是"关掉标签页"，最弱的是"再申请一次"（重新走闸门，等待时间会更长）。
6. **当天娱乐总额用完：** 今天不能再申请，遮罩只剩"去学德语"和"关掉"。
7. 如果页面是视频页，并且读到了频道，遮罩上还会出现"这是德语 / 学习视频（记住 UP 主 xxx）"。标记后立即放行，这段时间不算娱乐。

### 3.5 德语入口

- **继续上次的德语：** 自动记住最近一次德语页面的 URL 和标题。
- **德语入口列表：** 在设置页配置，比如 Nicos Weg 的课程页、AnkiWeb。
- 出现在三个地方：闸门 / 拦截遮罩的主按钮、popup。

### 3.6 私密站点：冷静期

用户的原话是：频率因人而异，没有越多越不好；但下意识地进去、出来才发现过了很久，这就浪费了时间。所以这里不禁止，而是**在进入前制造一个清醒的停顿**：

- **白天打开时：** 先进入 3 分钟冷静期。遮罩建议离开屏幕做一件身体上的事：冷水洗脸、15 个俯卧撑、喝水走走。
  - 任何时候都可以"不想了，关掉"，记一次"冷静后离开"。
  - 冷静期满后才能进入，可停留 20 分钟，每天 1 次。
- **收尾和宵禁期间：** 一律拦截，不可延长。
- **隐私：** 报告、遮罩和事件日志都不显示具体网站。

## 4. 功能清单（v3.0.0）

| # | 功能 | 验收标准 |
|---|------|---------|
| F1 | 计时 | 只计聚焦窗口里当前标签页的时间。无输入时：看视频或页面在出声 → 继续计时；锁屏 → 停表。每 30 秒落库一次 |
| F2 | 分类 | 四个类别；规则优先级为 手动改判 > 频道 > 网址 > other；B 站和 YouTube 能读出频道 |
| F3 | 时段策略 | 白天 / 收尾 / 宵禁三种判决，由纯函数实现，全部用表驱动测试覆盖 |
| F4 | 页面内遮罩 | 闸门、拦截和倒计时都在页面内完成，已经打开的标签页立即生效，单页应用的站内跳转也能拦住 |
| F5 | 意图闸门 | 意图 + 时长 + 递增等待；通行证到期后拦截；当天总额封顶 |
| F6 | 宵禁 | 白名单放行；可延长 1 次，必须写理由 |
| F7 | 频道标记 | 在遮罩或 popup 上一键把 UP 主或频道标记为德语、学业或娱乐 |
| F8 | Popup | 当前时段和倒计时、今日德语对比目标、今日娱乐对比上限、当前页面归属和改判、继续德语 |
| F9 | 报告页 | 每晚最后上网时间对比 23:00（14 晚）、德语每日分钟数对比目标和连续天数、今日 24 小时时间线、类别和热门站点、意图日志（"说要看 10 分钟，实际看了多久"）、宵禁延长理由 |
| F10 | 设置页 | 作息时间、德语目标和入口、娱乐上限和时长档位、宵禁白名单、网址规则、频道规则、数据导出和清空、隐身授权状态 |
| F12 | 私密冷静期 | 冷静期满才能进入，可以随时离开；每日次数；夜间拦截；任何地方都不暴露域名 |
| F13 | 「纸与夜」视觉 | 白天纸面、夜间深蓝，由作息驱动；宋体标题、衬线数字；只用系统字体（ADR-0015） |
| F11 | 徽章 | 白天显示今日德语分钟数（绿色）；收尾期显示距上床的分钟数（琥珀色）；宵禁期显示 `zZ` |

## 5. 关键流程

- **白天走神：** 输入 live.bilibili.com → 遮罩问意图 → 等 5 秒 → 选"放松一下 · 10 分钟" → 右下角开始倒计时 → 到点后遮罩出现 → 点"去学德语"，回到 Nicos Weg 上次那一课。
- **B 站德语视频：** 打开某个德语 UP 主的视频 → 遮罩上有"这是德语视频（记住 UP 主 xxx）" → 点一下 → 放行，计入德语。下次这个 UP 主的视频直接算德语，不再弹遮罩。
- **晚上：** 22:30 起 B 站进不去，其他页面右下角显示"距上床 28 分钟"。23:00 起几乎所有页面都被遮住，显示"该睡了"。真有急事，写理由延长 10 分钟。
- **第二天早上：** 打开报告页，看到"昨晚最后上网 23:04"，以及近 14 晚的按时率。

## 6. 技术要点（详见 design/architecture.md）

- 技术栈不变：WXT + React + TypeScript + Dexie + vitest + Playwright。
- 计时状态机改为"对账"模型。依据三类证据决定是否计时：有没有用户输入、有没有声音或视频在播放、有没有锁屏。每次心跳落库一个片段（ADR-0014）。
- 拦截从按域名重定向（DNR）改为页面内的内容脚本遮罩。判决由后台按完整 URL 加频道信号给出（ADR-0013）。
- 业务判断全部放在 `src/core` 的纯函数里，包括 policy、classify、tracker、metrics。
