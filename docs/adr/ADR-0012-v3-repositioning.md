# ADR-0012 v3 重定位：作息 + 德语

- 状态：已采纳（2026-10-14）
- 取代：v2 产品方向（`archive/v2/PRODUCT-v2.md`），以及 ADR-0010（OpsDeck 主题变体）和 ADR-0011（61 站目录）中的产品部分

## 背景

对 v2.0.0 做了一次意图审计（2026-10-14）。代码的工程外壳是完整的，但核心承诺没有兑现：

- 看视频不碰鼠标 60 秒就停止计时，正在进行的时长也不计入预算。
- 拦截按域名做，会把德语课一起拦掉。默认档位是"只提醒"，永远不会拦。
- 已经打开的单页应用页面拦不住。
- 意图闸门和频道识别从来没有实现。
- MVP 的验收标准是"自用一周"，这一步从来没有执行。

用户随后重新说明了真实目标：23:00 上床、07:30 起床；把漫无目的刷 B 站直播和 X 视频的时间，换成学德语的时间；看清网页时间花在了哪里。

## 决策

1. 产品围绕三个时段（白天 / 收尾 / 宵禁）和一个正向指标（德语）重建。类别固定为 德语 / 学业 / 娱乐 / 其他。
2. 白天的娱乐站走"意图闸门 + 限时通行证 + 递增等待 + 每日封顶"，取代"类别预算 + 豁免"。
3. 宵禁采用全局拦截加白名单，每晚可延长 1 次，必须写理由。
4. 内容级区分靠频道规则实现（B 站 UP 主、YouTube 频道），首次出现时询问一次并记住。
5. 删除：主题强调色变体、61 站目录、专注模式、暂停监督、DNR 重定向、引导页。专注模式的作用被宵禁和闸门取代；暂停监督是"后门"。

## 后果

- 配置项大幅减少，概念从"类别 × 档位 × 预算 × 豁免"简化为"时段 × 类别"。
- 旧数据不迁移，新库名为 SurfWardenV3。v2 实际上没有被持续使用，迁移的价值很低。
- 验收必须包含真机自用。用 E2E 加单测证明逻辑正确，用一周自用证明产品有效。
